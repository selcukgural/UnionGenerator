# UnionGenerator.AspNetCore.SourceGen

Compile-time source generator for ultra-fast union-to-HTTP response conversion in ASP.NET Core. **Phase 2 in development** - Creates optimized, zero-reflection code for converting union types to IActionResult with automatic status code mapping.

## 🚀 Quick Start

This package is **automatic** - no setup required! Just install and let it work.

```bash
dotnet add package UnionGenerator.AspNetCore.SourceGen
```

> **Note**: Phase 2 implementation in progress. Foundation complete, full code generation coming Q1 2026.

---

## 🎯 What This Does

Instead of reflection at runtime to convert union types to HTTP responses, this generator creates optimized code **at compile time**.

**Before** (Runtime Reflection - Current UnionGenerator.AspNetCore):
```csharp
// Uses reflection to detect union type and status codes
public IActionResult ToActionResult(this Result<User, Error> result)
{
    var type = result.GetType();
    var isSuccessProperty = type.GetProperty("IsSuccess"); // Reflection!
    var statusCodeProperty = type.GetProperty("StatusCode");
    // ... more reflection ...
}
// Performance: ~100 µs per call
```

**After** (Generated Code - Future Phase 2):
```csharp
// Generated by source generator - ZERO reflection
public static IActionResult ToActionResult(this Result<User, Error> result)
{
    if (result.IsSuccess)
        return new OkObjectResult(result.Data);
    
    return new ObjectResult(result.Error) 
    { 
        StatusCode = result.Error.StatusCode 
    };
}
// Performance: ~10-100 ns per call (1000x-10,000x faster!)
```

## 📁 What Gets Generated (Phase 2)

For each union type combination, the generator will create:

### 1. Extension Method

```csharp
// Generated: Result_User_Error_Extensions.cs
public static class Result_User_Error_Extensions
{
    public static IActionResult ToActionResult(
        this Result<User, Error> result, 
        int successStatusCode = 200)
    {
        if (result.IsSuccess)
            return successStatusCode switch
            {
                200 => new OkObjectResult(result.Data),
                201 => new CreatedResult(string.Empty, result.Data),
                204 => new NoContentResult(),
                _ => new ObjectResult(result.Data) { StatusCode = successStatusCode }
            };
        
        return new ObjectResult(result.Error) 
        { 
            StatusCode = result.Error.StatusCode 
        };
    }
}
```

### 2. Status Code Constants

```csharp
// Generated inline or in companion class
internal static class StatusCodes
{
    public const int NotFoundStatusCode = 404;
    public const int ValidationStatusCode = 422;
    public const int ConflictStatusCode = 409;
}
```

### 3. Property Accessors (Optimized)

```csharp
// Generated compiled accessors (compiled to IL, super fast)
private static readonly Func<Result<User, Error>, int> GetErrorStatusCode = 
    result => result.Error.StatusCode;
```

## 🔧 How It Will Work

### 1. Detection Phase
```
Generator scans for:
├── Union types (classes with 2+ static factory methods)
├── Error cases (methods returning union)
└── Status code declarations ([UnionStatusCode], properties)
```

### 2. Analysis Phase
```
Analyzes each union:
├── Success type (T)
├── Error type (E)
├── Error status code
└── Custom attributes
```

### 3. Generation Phase (Phase 2)
```
Generates optimized code:
├── Extension methods
├── Type checks
├── Property access
└── Response mapping
```

### 4. Compilation
```
Generated code compiled together with your project
No runtime overhead!
```

## 📚 Integration Examples

### Example 1: Basic Union

**Your Code**:
```csharp
[GenerateUnion]
public partial class Result<T, E>
{
    public static Result<T, E> Success(T data) => new SuccessCase(data);
    public static Result<T, E> Error(E error) => new ErrorCase(error);
}

public class User { public int Id { get; set; } public string Name { get; set; } }

[UnionStatusCode(404)]
public class NotFoundError { public string Message { get; set; } }
```

**Generated (Phase 2)**:
```csharp
public static class Result_User_NotFoundError_Extensions
{
    public static IActionResult ToActionResult(
        this Result<User, NotFoundError> result,
        int successStatusCode = 200)
    {
        if (result.IsSuccess)
            return new OkObjectResult(result.Data) { StatusCode = successStatusCode };
        
        return new ObjectResult(result.Error) 
        { 
            StatusCode = 404 // Hardcoded from [UnionStatusCode]!
        };
    }
}
```

**Usage** (unchanged, just faster):
```csharp
[ApiController]
[Route("api/[controller]")]
public class UsersController : ControllerBase
{
    [HttpGet("{id}")]
    public IActionResult GetUser(int id)
    {
        return _service.GetUser(id).ToActionResult(); // Now uses generated code!
    }
}
```

### Example 2: Multiple Error Types with Different Status Codes

**Generated** (for each combination):

### Example 3: Minimal API with Generated Adapters

**Your Code**:
```csharp
var builder = WebApplication.CreateBuilder(args);
builder.Services.AddUnionResultHandling(); // Uses generated code when available
var app = builder.Build();

app.MapGet("/users/{id}", (int id, IUserService service) =>
    service.GetUser(id).ToActionResult()) // Generated extension!
    .Produces<User>(200)
    .Produces<NotFoundError>(404)
    .WithName("GetUser");

app.Run();
```

## 💡 Design Principles

### 1. Zero Reflection
Generated code uses direct property access, not reflection.

### 2. Hardcoded Constants
Status codes are constants in generated code, not looked up at runtime.

### 3. Type-Specific
Separate extension for each Result<T, E> combination avoids generics overhead.

### 4. No Allocations
Generated code allocates minimal objects (reuses known types).

### 5. Debuggable
Generated code is readable and breakpoint-able.

### 6. Backwards Compatible
Seamlessly enhances existing UnionGenerator.AspNetCore usage.

## 🐛 Troubleshooting

### Generated Code Not Appearing

**Problem**: Generated extensions not visible

**Solution**:
1. Install UnionGenerator.AspNetCore.SourceGen package
2. Rebuild project: `dotnet clean && dotnet build`
3. Check Phase 2 implementation status (may be in progress)
4. Check `obj/Debug/` for generated files

### Type Not Found in Generated Extension

**Problem**: Compiler can't find generated extension

**Solution**:
1. Ensure UnionGenerator.AspNetCore is also installed (base package)
2. Add using statements for relevant namespaces
3. Rebuild project
4. Check that union type has proper factory methods
